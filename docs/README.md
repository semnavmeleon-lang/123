# Надстройка Outlook «Сохранить письмо»

Веб-надстройка (Office.js task pane) для Outlook: добавляет кнопку **«Сохранить письмо»**
на ленту при просмотре письма. По нажатию письмо (тема, отправитель, получатели, тело
и обычные вложения) скачивается на компьютер в виде файла `.eml` через папку «Загрузки» браузера.

Работает в новом Outlook, Outlook в браузере (OWA), классическом Outlook для Windows и Outlook для Mac.

Файлы раздаются **локально**, с вашего компьютера через `python`, а не с внешнего хостинга —
Outlook всё равно требует HTTPS даже для localhost, поэтому нужен самоподписанный сертификат
и он должен быть один раз добавлен в доверенные (иначе Outlook откажется грузить страницу).

## 1. Подготовить сертификат и запустить локальный сервер

1. Установите зависимость (один раз):
   ```
   pip install cryptography
   ```
2. Сгенерируйте сертификат для `localhost` (один раз, из корня репозитория):
   ```
   python tools/generate_cert.py
   ```
   Появятся файлы `tools/localhost-cert.pem` и `tools/localhost-key.pem`.
3. **Добавьте сертификат в доверенные** (иначе Outlook покажет ошибку сертификата), в PowerShell
   **от имени администратора**:
   ```
   Import-Certificate -FilePath tools\localhost-cert.pem -CertStoreLocation Cert:\LocalMachine\Root
   ```
   Либо вручную: дважды кликните `localhost-cert.pem` → **Установить сертификат** →
   **Локальный компьютер** → «Поместить все сертификаты в следующее хранилище» →
   **Доверенные корневые центры сертификации** → Готово.
4. Запустите сервер и оставьте окно открытым, пока пользуетесь надстройкой:
   ```
   python tools/serve.py
   ```
   Он поднимет `https://localhost:3000/` и будет отдавать `manifest.xml`, `taskpane.html` и иконки
   из папки `docs/`.

Если сервер не запущен — надстройка перестаёт работать (кнопка на ленте останется, но панель
не откроется). Так что перед использованием надстройки не забывайте запускать `python tools/serve.py`.

## 2. Установить надстройку в Outlook

### Новый Outlook / Outlook в браузере (OWA)
1. Откройте любое письмо → **⋯ (Ещё действия) → Получить надстройки** (Get Add-ins).
2. Слева выберите **«Мои надстройки» → «Добавить пользовательскую надстройку» → «Добавить из URL-адреса»**.
3. Вставьте ссылку на манифест: `https://localhost:3000/manifest.xml`.
4. Подтвердите установку.

### Классический Outlook (Windows) / Mac
1. **Файл → Управление надстройками** (или лента **Главная → Получить надстройки**).
2. **Мои надстройки → Добавить пользовательскую надстройку → Добавить из файла/URL**.
3. Укажите ссылку на манифест (см. выше) или скачайте `manifest.xml` и добавьте из файла.

После установки откройте любое письмо на чтение — на ленте появится кнопка **«Сохранить письмо»**,
которая откроет панель задач с кнопкой сохранения.

> Сервер должен быть запущен (`python tools/serve.py`) и при установке, и при каждом
> последующем использовании надстройки — Outlook подгружает `taskpane.html` заново при каждом
> открытии панели.

## Что сохраняется

- Тема, отправитель, получатели (To/Cc), дата — как заголовки письма.
- Тело письма в формате HTML.
- Обычные вложения (файлы), закодированные в письмо как часть `.eml`.
- «Облачные» вложения (ссылки на OneDrive/SharePoint) не скачиваются как файлы — только сам файл
  ссылки, если он есть, остальное нужно скачивать вручную по ссылке в письме.

Файл `.eml` — стандартный формат письма, открывается двойным кликом в Outlook, Почте Windows,
Thunderbird и большинстве других почтовых клиентов.

## Если что-то не так

- **Ошибка сертификата в браузере/Outlook** — сертификат не добавлен в «Доверенные корневые
  центры сертификации» (шаг 3) или сервер запущен с другим сертификатом, чем импортирован. Удалите
  `tools/localhost-*.pem`, сгенерируйте заново и повторите импорт.
- **Панель не открывается / «не удалось подключиться»** — не запущен `python tools/serve.py`.
- **Порт 3000 занят** — освободите его или поменяйте `PORT` в `tools/serve.py` и во всех ссылках
  `https://localhost:3000/...` внутри `docs/manifest.xml`.
