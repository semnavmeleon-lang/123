# Надстройка Outlook «Сохранить письмо»

Веб-надстройка (Office.js task pane) для Outlook: добавляет кнопку **«Сохранить письмо»**
на ленту при просмотре письма. По нажатию письмо (тема, отправитель, получатели, тело
и обычные вложения) скачивается на компьютер в виде файла `.eml` через папку «Загрузки» браузера.

Работает в новом Outlook, Outlook в браузере (OWA), классическом Outlook для Windows и Outlook для Mac.

## 1. Включить хостинг файлов (GitHub Pages)

Outlook требует, чтобы файлы надстройки (`manifest.xml`, `taskpane.html`, `taskpane.js`, иконки)
были доступны по HTTPS — открыть их с диска нельзя.

1. В репозитории на GitHub: **Settings → Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: выберите `main` (после слияния этой ветки) и папку **`/docs`**, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://semnavmeleon-lang.github.io/123/`
5. Проверьте, что манифест открывается: `https://semnavmeleon-lang.github.io/123/manifest.xml`.

Файлы в `manifest.xml` уже ссылаются на этот адрес — менять ничего не нужно, если репозиторий
и включённые Pages совпадают с указанными выше.

## 2. Установить надстройку в Outlook

### Новый Outlook / Outlook в браузере (OWA)
1. Откройте любое письмо → **⋯ (Ещё действия) → Получить надстройки** (Get Add-ins).
2. Слева выберите **«Мои надстройки» → «Добавить пользовательскую надстройку» → «Добавить из URL-адреса»**.
3. Вставьте ссылку на манифест: `https://semnavmeleon-lang.github.io/123/manifest.xml`.
4. Подтвердите установку.

### Классический Outlook (Windows) / Mac
1. **Файл → Управление надстройками** (или лента **Главная → Получить надстройки**).
2. **Мои надстройки → Добавить пользовательскую надстройку → Добавить из файла/URL**.
3. Укажите ссылку на манифест (см. выше) или скачайте `manifest.xml` и добавьте из файла.

После установки откройте любое письмо на чтение — на ленте появится кнопка **«Сохранить письмо»**,
которая откроет панель задач с кнопкой сохранения.

## Что сохраняется

- Тема, отправитель, получатели (To/Cc), дата — как заголовки письма.
- Тело письма в формате HTML.
- Обычные вложения (файлы), закодированные в письмо как часть `.eml`.
- «Облачные» вложения (ссылки на OneDrive/SharePoint) не скачиваются как файлы — только сам файл
  ссылки, если он есть, остальное нужно скачивать вручную по ссылке в письме.

Файл `.eml` — стандартный формат письма, открывается двойным кликом в Outlook, Почте Windows,
Thunderbird и большинстве других почтовых клиентов.

## Локальная разработка / отладка

Файлы обычные статические HTML/JS, специальной сборки не требуется. Для локальной проверки
можно поднять любой HTTPS dev-сервер (например, `npx office-addin-dev-certs install` +
`npx http-server -S -C cert.pem -K key.pem docs`) и подставить `https://localhost:PORT/...`
в `manifest.xml` перед боковой загрузкой (sideload) для тестов.
