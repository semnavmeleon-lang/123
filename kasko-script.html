Скрипт обзвона КАСКО

Интерактивный сценарий разговора с клиентом: приветствие → выявление потребности → работа с возражениями и конкурентами (в т.ч. переход по продукту «Legacy») → расчёт и оформление. Нажимайте вариант ответа, наиболее близкий к тому, что говорит клиент.

  • Документы о стоимости доп. оборудования — если оно страхуется

Документы предоставляются в составе фотокомплекта. Для полисов-оферт сбор предстраховой документации не требуется.

  • Никогда не запрашивайте номер карты, CVV-код или код из СМС — ни при каких обстоятельствах.
  • На вопрос об источнике контактов называйте только реальный источник, откуда взяты данные клиента.
  • Не оформляйте ТС, не проходящие по условиям продукта: такси/доставка/каршеринг/аренда/маршрутки; более 3 собственников-физлиц (кроме отдельных исключений); дубликат ПТС без первоначального; технически неисправные или неидентифицируемые ТС.
  • Для Legacy: только подержанный автомобиль, ранее застрахованный в другой компании; перерыв между окончанием старого полиса и началом нового — не более 30 календарных дней; для скидки нужен скан предыдущего полиса.
  • Не обещайте скидку сверх предусмотренной продуктом — по индивидуальным запросам передавайте вопрос руководителю.
  • При категоричном отказе или просьбе не звонить — фиксируйте это, повторный звонок по этому вопросу недопустим.
  • Каждый звонок фиксируйте в CRM с результатом и точными договорённостями о повторном контакте.
  • Соблюдайте допустимые часы для звонков согласно внутреннему регламенту компании.
  • При недозвоне фиксируйте статус «недозвон» и соблюдайте интервал повторных попыток — не звоните подряд многократно за короткий срок.
  • При грубости со стороны клиента не вступайте в конфликт — вежливо завершайте разговор.

Продуктовые данные приведены по внутренней методичке «Автокаско для физических лиц». Перед звонками сверяйте актуальные скидки, тарифы и условия продуктов с действующим регламентом — линейка может обновляться.
