# VSK OSAGO — пакетная проверка пролонгации

Chrome-расширение (Manifest V3): читает номера полисов из Excel-файла,
прогоняет каждый через форму проверки пролонгации на `lka.vsk.ru`,
и записывает результат в единственную выбранную колонку того же файла.
Никаких прямых HTTP-запросов к бэкенду ВСК — всё идёт через настоящую
страницу в вашем браузере с вашей авторизацией, расширение просто
нажимает то же самое, что нажимали бы вы руками.

## Установка

1. `chrome://extensions` → включить «Режим разработчика» (переключатель
   в правом верхнем углу).
2. «Загрузить распакованное расширение» → выбрать папку `extension/`.
3. Открыть панель: клик по иконке расширения на панели инструментов
   Chrome (иконка по умолчанию — свой значок не задавали).

## Использование

Панель управления открывается в отдельной вкладке и должна оставаться
открытой всё время прогона — в ней хранится состояние и дескриптор
файла.

1. **Файл.** «Открыть Excel-файл…» — выберите `.xlsx`.
2. **Колонки.** Выберите колонку с номерами полисов и колонку для
   результата (должны уже существовать в файле — добавьте пустую
   колонку в Excel заранее, если нужно). Выбор запоминается по
   названию заголовка для следующих запусков. В работу берутся только
   строки, где ячейка результата ничем не закрашена и не содержит
   комментария — остальные считаются уже обработанными вручную и
   пропускаются.
3. **Элементы страницы.** Семь независимых элементов, у каждого своя
   кнопка «Назначить» и своя «Сбросить» — можно переназначить один
   элемент, не трогая остальные:
   - чекбокс «Предыдущий полис ВСК» — у него отдельная галочка
     «Пропускать этот шаг»: если включить, расширение не будет ни
     искать, ни отмечать этот чекбокс (и назначать ему селектор не
     нужно) — полезно, когда для части полисов «предыдущего полиса
     ВСК» нет и отмечать нечего;
   - поле ввода номера полиса;
   - кнопка «Найти» (нажимается сразу после ввода номера);
   - кнопка «Продолжить», **пока она ещё неактивна** — кликается сразу
     после «Найти», до загрузки данных полиса;
   - кнопка «Продолжить», **когда она уже активна** — кликается после
     того, как данные подтянулись;
   - варианты результата «Цена» и «Невозможно рассчитать» — их можно
     назначить вручную (когда нужный экран уже открыт в рабочей
     вкладке), либо не трогать и один раз показать «на лету» во время
     обычного прогона (см. ниже).

   На проверке расширение ждёт появления именно элемента с селектором
   «активной» кнопки и кликает по нему — двух разных кликов при
   назначении достаточно, чтобы не полагаться на угадывание, что
   именно на сайте означает «неактивна» (атрибут `disabled`, класс,
   `aria-disabled` — не важно). Если оба клика случайно попадут на один
   и тот же селектор (например, у кнопки стабильный `id`, и клики не
   отличаются ничем, что меняется между состояниями) — панель предупредит
   об этом в журнале, тогда стоит выбрать более точное место клика.

   «Назначить» для всех элементов формы сам открывает
   `lka.vsk.ru/products/forge/osago` в рабочей вкладке. Для вариантов
   результата навигация не форсируется — сначала откройте в рабочей
   вкладке нужный экран сами. Клики во время назначения форму не
   отправляют — только запоминают элемент.
4. **Запуск.** «Начать проверку» — расширение само проходит по всем
   отобранным строкам: открывает страницу, ждёт (не по таймеру, а по
   реальному появлению элементов) чекбокс/поле/кнопку «Найти», отмечает
   чекбокс, вводит номер, жмёт «Найти», дожидается появления активной
   «Продолжить», жмёт её, затем ждёт результат. Если по строке за
   разумное время нет вообще никакого ответа (вкладка зависла или ушла
   на непредвиденную страницу) — строка помечается ошибкой в журнале и
   в файле, и работа продолжается со следующей.

### Первое распознавание результата

Систему может вернуть один из двух исходов — цену или сообщение
о невозможности расчёта. За один прогон виден только один из них,
поэтому оба селектора расширение просит показать «на лету»: как
только на странице появляется исход, для которого ещё нет
сохранённого селектора, прогон ставится на паузу и в панели
появляется запрос «кликните на результат», а затем — «это цена или
невозможно рассчитать?». После первого раза по каждому из двух
исходов подсказки больше не нужны, и весь список проходит уже без
остановок.

Если ВСК позже поменяет вёрстку страницы и какой-то селектор перестанет
попадать — «Сбросить» у конкретного элемента сбрасывает обучение только
для него, остальные не трогаются, и его можно назначить заново без
переустановки расширения.

## Как записывается результат

Файл не перечитывается и не пересобирается целиком через обычный
экспорт Excel-библиотеки — это способно незаметно изменить
форматирование, стили или потерять комментарии в других ячейках.
Вместо этого расширение точечно редактирует XML внутри самого .xlsx
(это zip-архив): находит нужную ячейку в листе, меняет только её
значение, и пересобирает архив, не трогая `styles.xml`, комментарии,
другие листы и остальные ячейки. Проверено: после записи в одну ячейку
остальные строки, их заливка и комментарии остаются побайтово
идентичны исходному файлу.

## Устройство (коротко)

- `shared.js` — общие тайминги (`FORM_WAIT_MS`, `RESULT_WAIT_MS`,
  `ROW_TIMEOUT_MS`), подключается и в content.js, и в панель.
- `manager.html` / `manager.js` — управляющая вкладка: чтение Excel
  (SheetJS, `lib/xlsx.full.min.js`, с разбором стилей и комментариев
  для фильтра по строкам), точечная запись результата (`lib/jszip.min.js`
  + `lib/xlsx-cell-writer.js`), независимое назначение/сброс каждого
  из семи селекторов, цикл прогона со сторожевым таймаутом на строку,
  журнал.
- `content.js` — инжектится на `lka.vsk.ru/*`. Автономно продолжает
  прогон после навигации (состояние — в `chrome.storage.local`, ключ
  `run`), ждёт элементы через `MutationObserver` (защитный таймаут —
  верхняя граница на случай сбоя страницы, а не способ определить
  готовность), плюс режим «укажи элемент мышью» для обучения.
- `background.js` — открывает/фокусирует вкладку панели по клику на
  иконку расширения.

## Известные ограничения

- Учитывает, что «Продолжить» может привести как к обновлению той же
  SPA-страницы, так и к полной навигации на другой URL — оба случая
  покрыты, но конкретную вёрстку `lka.vsk.ru` расширение не знает
  заранее: все селекторы задаются вами через клики, ничего не
  захардкожено.
- Сторожевой таймаут на строку (по умолчанию сумма таймаутов внутри
  content.js плюс запас, около 5 минут) — если реальная проверка на
  сайте штатно занимает дольше, строки будут ошибочно помечаться как
  зависшие; значение задано в `shared.js`.
