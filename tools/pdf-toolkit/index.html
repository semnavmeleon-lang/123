PDF Утилита

Всё работает локально в браузере — файлы никуда не отправляются
Файлы

Объединить PDF

Выберите несколько PDF-файлов из пула (или добавьте новые) и объедините их в один в нужном порядке.

    Разделить PDF

    Разбейте PDF на отдельные страницы или на несколько файлов по диапазонам.

    Организовать страницы

    Извлекайте, удаляйте, поворачивайте и переставляйте страницы в одном месте — можно добавить страницы из другого файла пула, как в Adobe Acrobat.

    Изображения в PDF

    Соберите PDF из изображений (JPG, PNG, WebP). Порядок можно менять перетаскиванием.

    PDF в изображения

    Экспортируйте страницы PDF как изображения PNG или JPEG.

    Извлечь текст

    Извлеките текстовое содержимое PDF (без OCR — только текстовый слой документа).

    Извлечь изображения

    Извлеките встроенные растровые изображения из PDF (без учёта векторной графики).

    Водяной знак

    Добавьте текстовый водяной знак на все страницы одного или нескольких документов.

    Метаданные

    Просмотрите и отредактируйте метаданные документа.

    Заполнить форму

    Заполните поля интерактивной PDF-формы (AcroForm).

    Пароль / защита

    Установите пароль на открытие для одного или нескольких PDF (RC4 128-бит, стандартный защитный механизм PDF). Работает только с незашифрованными файлами.

    Сжать PDF

    Уменьшите размер одного или нескольких файлов: пересжатие встроенных JPEG-изображений и оптимизация структуры документа.
