# PDF Утилита

Браузерная утилита для работы с PDF: объединение, разделение, извлечение и
удаление страниц, поворот, конвертация в/из изображений, извлечение текста
и изображений, водяные знаки, метаданные, заполнение форм, установка пароля
и базовое сжатие.

Всё работает **полностью в браузере** — файлы не отправляются ни на какой
сервер, обработка идёт локально с помощью [pdf-lib](https://pdf-lib.js.org/),
[pdf.js](https://mozilla.github.io/pdf.js/) и [JSZip](https://stuk.github.io/jszip/).

## Запуск

Из-за использования Web Worker (pdf.js) и `fetch()` (загрузка шрифта для
кириллицы) страницу нужно открывать через локальный веб-сервер, а не просто
двойным щелчком по `index.html` (браузеры блокируют это для страниц,
открытых по протоколу `file://`).

Любой простой статический сервер подойдёт, например:

```bash
cd pdf-toolkit
python3 -m http.server 8080
# затем откройте http://localhost:8080/
```

или `npx serve .`, или разместите папку на любом статическом хостинге
(GitHub Pages и т.п.).

## Функции

- **Объединить PDF** — несколько файлов в один, с изменением порядка.
- **Разделить PDF** — по одной странице (ZIP) или по диапазонам.
- **Извлечь страницы** — сохранить выбранные страницы в новый файл.
- **Удалить страницы** — убрать отмеченные страницы.
- **Изменить порядок** — перетаскивание миниатюр или стрелки.
- **Повернуть страницы** — все сразу или по отдельности, на 90/180/270°.
- **Изображения в PDF** — JPG/PNG/WebP → PDF, с заданным размером страницы.
- **PDF в изображения** — экспорт страниц в PNG/JPEG с выбором масштаба.
- **Извлечь текст** — постранично, с выгрузкой в `.txt`.
- **Извлечь изображения** — встроенные растровые изображения → PNG/ZIP.
- **Водяной знак** — текст (кириллица поддерживается), поворот, прозрачность,
  по центру или мозаикой.
- **Метаданные** — просмотр и редактирование Title/Author/Subject/Keywords/
  Creator/Producer.
- **Заполнить форму** — текстовые поля, чекбоксы, радиокнопки, списки; опция
  "сделать неизменяемыми" (flatten).
- **Пароль / защита** — RC4 128-бит (/V 2 /R 3), пароль на открытие и
  отдельный пароль владельца, гибкие разрешения (печать/копирование/
  редактирование). Работает только с незашифрованными исходными файлами.
- **Сжать PDF** — пересжатие встроенных JPEG-изображений с выбором качества
  + структурная оптимизация файла.

## Технические детали

- Все сторонние библиотеки (`pdf-lib`, `pdf.js`, `JSZip`, `fontkit`, шрифт
  DejaVu Sans для поддержки кириллицы) находятся в `vendor/` — интернет для
  их загрузки не требуется.
- Шифрование PDF реализовано вручную (`js/crypto-rc4.js` +
  `js/pdf-encrypt.js`) по алгоритму стандартного защитного механизма PDF
  (ISO 32000-1, RC4/MD5), так как pdf-lib не поддерживает шифрование.
  Корректность проверена сквозным тестом против независимой реализации
  (pdf.js: открытие правильным/владельческим паролем, отклонение неверного).
